# 默认邻接参照与精确可达前沿切换

2026-10-23，用户明确选择“默认几何依旧选旧的连接相邻 Pareto 点的描绘方式，但是明确标明这个不是帕累托面，并附转换实际前沿的 toggle”，随后确认旧方式就是 demo 中的 Delaunay 邻接插值。本页记录该选择及必要工程展开；不是把后续第三方案或历史 UX 建议升级为用户批准。

随后用户要求：“标识位置和可达面展示切换 toggle 位置隔得太远了.标识位置应该放到 TOGGle 位置旁边;且要是可以收起且会自动在1分钟后收起的”。因此说明由图内改至开关旁，使用可展开的紧凑标识。

## 实现范围与验收

- 默认仍为旧的 Delaunay 邻接线框，参照的顶点、三角索引和线段不变。可继续选择参照实心或隐藏参照。
- 开关旁保留“非帕累托面”标识，精确模式显示“精确可达面”。点击标识展开或收起详细说明；默认展开，一分钟后自动收起。手动收起取消旧计时，每次重新展开重新计时一分钟；切换几何或口径只更新说明文字，不重新展开或重置计时。收起说明不改变可达面展示。
- 详细说明位于开关及标识紧邻的下一行，与它们共用有宽度上限的容器；窄屏横滑工具栏时一起移动，内容可完整换行。按钮支持键盘、`aria-expanded`、`aria-controls` 及可见焦点。
- 勾选“实际可达前沿（精确阶梯）”时隐藏邻接描绘，展示合并平台、相邻可达平台间立面及边线；取消后恢复先前的参照外观。四口径切换保留选择，视角、模型与分析结果不因几何切换而改变。
- 精确性仅相对于输入契约中已展示且参与该口径分析的 Pareto 点。在成本预算与速度下限给定时取最高可达智能；不可达区留白，不封箱底。厂商与模型显示过滤不重新定义这份全局分析点集。
- 复用独立 demo 的纯几何算法。正式 HTML 渲染器按预算轴原有 log/linear 刻度派生精确几何，再还原为原始坐标单位。持久 v2 输入及原邻接几何只读；旧采样可达网格在 HTML 的独立副本中替换，不需要公共 v3 迁移。
- 不增加平滑第三方案，不实施三条历史 UX 建议，不抓取网页、不写共享输出，不自动提交或部署本次新增改动。

改动面为正式 HTML 渲染器及其 JS/CSS/bundle、具名场景几何适配器、针对性单测/浏览器测试，以及 demo 的默认选择说明。
