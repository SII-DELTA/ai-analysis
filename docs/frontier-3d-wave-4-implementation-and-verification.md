## 实际实现

v3 生成通过纯数组构造邻接三角、边线及预算阶梯，复用已入 main 的精确平台、立面和边界算法。
旧平台算法保留用于迁移对拍。默认邻接参照、精确面切换和说明折叠沿用既有行为。
完整契约不再保存 Plotly 副本，PNG/SVG 从已有场景按需装配，已实际导出并检查。

公共模型表按真实 UUID 去重；旧输入缺少 UUID 时保留显式弱身份。公共字段冲突拒绝生成，
旧 v2 的派生分组标签可作为引用差异保留。完整契约和浏览器投影分别有 JSON Schema，
另外拒绝非有限数、浏览器不能表示的大整数、无效预算轴、越界引用及坐标与公共 panel 不一致。
投影保留完整搜索解释，24 家显示厂商的 logo 来自四口径并集；完整审计 JSON 保留全部厂商资产。

推理档位使用目录 release/effort，同 release 的显示点与未上图记录共用同一解析器；
没有目录信息的旧输入仍保留名称降级。跨代谱系继续只连接显式家族。
厂商 UUID 注册依据来自冻结 API 的 54 家已有注册厂商，并补 IFM 名称别名；
当前显示并集仍有 Celeris 未注册，构建在 stderr 明确告警，不猜总部或品牌资产。

API 单页最多请求三次，仅重试连接错误、超时、429 和选定 5xx；
普通 4xx 不盲重试，Pro 403 的 Free 回退保持原逻辑。Retry-After 超过 30 秒等待预算时停止该轮，
保留原始失败，不提前请求。已批准的网页冷却、挑战停止和 TLS 回退没有改写。

轴标注按 viewport 缓存尺寸；相机运动不再重复读 offsetWidth/offsetHeight。
移除完整 window.THREE，测试通过限定构造器和诊断方法核验；默认不保留绘图缓冲。
实测发现旧版 320px 长速度轴名会使智能标题隐藏，已补 36/12px 备用偏移位置，
保持同一轴段与 48px 位移上限，新增纯函数反例并通过真实 DOM 裁切/避让验证。
