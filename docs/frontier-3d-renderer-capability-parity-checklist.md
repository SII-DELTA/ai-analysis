# Frontier 3D 渲染器能力对等清单

历史参照为 Plotly 版本 `a38a9b8`；W2 从 `0765a10` 开始。状态只描述实现与验证，不代表集成或部署。

| 能力 | Plotly 时代 | three.js 基线 | W2 / W3 验收或归属 |
|---|---|---|---|
| 四口径切换、相机保持 | 支持 | 支持 | 四口径浏览器参数化回归 |
| 轴刻度、投影标注 | 支持 | 支持 | 纯函数单测与标注浏览器回归 |
| 半透明面后方模型可见且可拾取 | 存在遮挡问题 | 曲面写深度导致不可见但可拾取 | D-5 已确认着色透出，像素断言 |
| hover、整组固定、谱系前身 | 支持 | 拖拽、宽限和筛选存在状态缺口 | W2 状态与可见结果断言 |
| 跨口径固定 | 原实现也清空 | 清空 | W2 UUID 保留及缺席原因 |
| 同档位跨代谱系 | 按每代代表点 | 按每代代表点且泛化误连 | W2 显式家族及同档位线 |
| 多档位关系线 | 支持 | WebGL 原生线宽无效 | W2 宽线与前景高亮 |
| Pareto 身份、突出度 | 同环表达 | 同环表达且小环被遮 | W2 身份环与光晕拆分 |
| tooltip 完整数值和单位 | 较完整 | 缺部分字段 | W3 三段详情、备用口径、冗长度、有效位与契约单位；旧 v2 降级 |
| 固定比较字段、权重说明与重置 | 支持 | 缺失 | W3 侧栏摘要与底部表、字段持久化、基准百分比、权重草稿和重置 |
| 搜索键盘导航与未上图原因 | 部分支持 | 缺失 | W3 全字段与排除记录、40 组总数、键盘与真实按钮 |
| WebGL 恢复、异常可见提示 | 依赖 Plotly | 恢复后未请求绘制 | W2 自动化恢复测试 |
| 窄屏与触屏信息界面 | 部分支持 | 有已知缺口 | W3 稳定页头、44px 折叠、视图设置与首次轻点详情 |
| 静态导出 | Plotly/kaleido | 仍保留 Plotly 适配 | W2 回归；W4 决定后续架构 |
| 自包含、无外部网络、指纹 | 支持自包含 | 已有 W1 指纹 | W2 浏览器与 bundle 一致性回归 |
| 恒定像素标记与尺寸偏好 | 缩放行为不同 | 世界空间尺寸 | W3 0.5–1.5×，1× Logo 容器 22 CSS px，zoomToCursor |
| 固定显示轴域与谱系前身 | 全谱系参与轴域 | 全谱系参与轴域 | W3 完整有限显示集合定域，前身夹紧并保留原值 |
| 品牌 fallback、许可与商标 | 不完整 | 两类共用生成器 | W3 方形 wordmark/monogram 分离、HTML 内嵌 MIT |

2026-10-28：W3 已实施，实际验证结果见 [W3 交付说明](frontier-3d-wave-3-implementation-and-verification.md)。W4 方法学、v3、生产输入有限性边界验证和产物瘦身继续由各自任务承担。此清单不代表提交、集成或部署。
